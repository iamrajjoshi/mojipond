# Security Policy

## Supported versions

Security fixes are provided for the latest published MojiPond release.

## Report a vulnerability

Please do not open a public issue for a suspected vulnerability. Use
[GitHub's private vulnerability reporting](https://github.com/iamrajjoshi/mojipond/security/advisories/new)
and include the MojiPond version, macOS version, reproduction steps, and the
potential impact.

If private vulnerability reporting is unavailable, wait for it to be enabled
rather than disclosing sensitive details publicly.
